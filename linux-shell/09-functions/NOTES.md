# 09 学習記録: 関数とローカル変数

## 関数の引数は `$1, $2...`(スクリプト全体の引数と同じ仕組み)

```bash
greet() {
  echo "hello, $1"
}
greet "riku"   # → hello, riku
```

`06`で見た「スクリプトの引数(`$1`, `$#`など)」と全く同じ特殊変数が、関数の中では「その関数を呼んだ時の引数」を指すように再利用される。呼び出し元の`$1`とは別物(関数の中に入ると上書きされる)。

## `local` を付けないとグローバル変数を書き換えてしまう(検証)

```
x=100
no_local() { x=999 }
no_local
after no_local, x=999      ← グローバルのxが書き換わってしまった

y=100
with_local() { local y=999; ... }
with_local
after with_local, y=100    ← localのおかげでグローバルのyは無事
```

シェル関数はデフォルトでは新しいスコープを作らず、代入した変数はそのままグローバル変数を上書きする。Pythonの関数(デフォルトでローカルスコープ)とは逆の挙動なので要注意。意図せずグローバルを汚染しないために、関数内で使う変数には基本的に`local`を付ける。

## 戻り値は「終了ステータス(0〜255)」であって、値そのものではない

```bash
is_even() {
  [ $(($1 % 2)) -eq 0 ] && return 0 || return 1
}
is_even 4   # exit=0 (真) → if is_even 4 で成功扱い
```

`return`は`07`の`if`と同じ「終了ステータスによる真偽」の仕組みに乗っている。0〜255の整数しか返せないため、文字列や大きな数値を「返したい」場合は`return`ではなく`echo`で出力し、呼び出し側で`sum=$(add 2 3)`のようにコマンド置換で受け取る(`add`関数で実演済み)。
