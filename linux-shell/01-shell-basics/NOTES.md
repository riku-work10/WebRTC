# 01 学習記録: シェルとは何か

## 確認したこと

```bash
echo $SHELL          # /bin/zsh                → ログインシェル(ログイン時にOSが起動するシェル)
dscl . -read /Users/$(whoami) UserShell   # /bin/zsh → macOSのユーザー情報に記録された値。$SHELLと一致した
zsh --version         # zsh 5.9 (arm64-apple-darwin25.0)
cat /etc/shells       # このOSで使用が許可されているシェル一覧(/bin/bash, /bin/zsh, /bin/csh など)
ps -p $$ -o pid,ppid,comm   # $$ = 今の(この)シェルプロセス自身のPID → 実体が/bin/zshであることを確認
```

## ログインシェル と インタラクティブシェル

```
ログインシェル(login shell)
   → ユーザーが最初にログインした時に起動するシェル。/etc/passwd(macOSではdscl管理)に記録される
   → 起動時に .zprofile / .zshenv などを読む

インタラクティブシェル(interactive shell)
   → 人間が対話的にコマンドを打ち込んで使うシェル(ターミナルアプリを開いた時など)
   → 起動時に .zshrc を読む

非インタラクティブシェル
   → シェルスクリプトを実行する時などに裏で起動されるシェル。プロンプトを表示しない
```

`echo $-`(オプションフラグ一覧)に`i`が含まれていればインタラクティブ、というのが判定方法。今回のターミナルでは`i`が含まれていた(`569JNRXghkl`のようにフラグが並ぶ中に`i`がある)。

## コマンドの探索順序

シェルが`echo`のようなコマンドを打った時に探す順番:

```
1. エイリアス(alias)        例: ls → ls -G
2. シェルの組み込みコマンド(builtin)  例: cd, echo, type 自体
3. シェル関数(function)
4. $PATHに列挙されたディレクトリを前から順に探す外部コマンド
```

`type コマンド名`でどの段階のものが実行されるか確認できる。このマシンでは`ls`はalias、`cd`と`echo`はbuiltinだった。`$PATH`は`:`区切りのディレクトリリストで、`echo $PATH | tr ':' '\n'`のように`tr`で改行に変換すると読みやすい(先頭に近いディレクトリほど優先される)。
